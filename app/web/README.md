# Erasmus AI — Web (`app/web`)

React + Vite + Tailwind client for the Erasmus AI assistant.

## Run

```bash
npm install
npm run dev
```

Set `VITE_API_BASE_URL` if the API is not at `http://localhost:4000` (see `src/api/config.ts`).

## Tests

```bash
npx vitest run
```

## Build

```bash
npm run build
```
